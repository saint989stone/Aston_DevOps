## 2010 – 2014
 Непосредственная работа с клиентами сегментов: B2С, B2B, B2G. Обработка Trouble Tickets
 по услугам связи, предоставляемых клиентам, КЦ ПАО "Ростелеком". Помощь в настройке
 клиентского оборудования, для корректной работы в сети передачи данных. Консультация
 клиентов по техническим вопросам. Устранение неисправностей связанных с работой сети
 передачи данных по технологиям ADSL и ETTH. Решение вопросов связанных с потерей
 несущей сигнала между оборудованием, настройкой абонентского порта мультиплексора
 доступа цифровой абонентской линии ADSL и коммутаторов ETTH, возникновением
 коллизий на сети провайдера, выходом из строя или некорректной работы оборудования
 провайдера. Опыт работы с оборудованием следующих фирм: мультиплексоры доступа
 цифровой абонентской линии ADSL (Siemens, Nokia, Natex), коммутаторами (Qtech, Cisco),
 маршрутизаторами Cisco.
## 2014 – 2021
 Внедрение, эксплуатация и совершенствование инженерно-технической защищенности в
 частности систем: охранной сигнализации, видеонаблюдения, контроля доступа и
 управления доступом на объектах компании. Подготовка и реализация проектов по
 оснащению техническими средствами охраны. Осуществление контроля за выполнением
 монтажных и пусконаладочных работ систем технических средств охраны. Реализация
 проекта удаленного мониторинга и управления техническими средствами охраны по сети
 передачи данных на основе программных средств, интегрированных в технические
 средства охраны, а также проверка сетевой доступности оборудования по средствам
 системы мониторинга Zabbix.
 С отличием завершил курсы по программе "Python для работы" онлайн школы SkillFactory.
 На основе полученных знаний реализован проект WEB приложения «База данных
 технических средств охраны» на основе: языка программирования Python; фреймворка
 Flask; SQL базы данных.
## 2021 - 2024
 Контроль и диагностика состояния сетевого оборудования, а также каналов сети передачи
 данных магистрального и регионального уровня. Обнаружение и оперативная эскалация
 обнаруженных аварий на сети в соответствующие подразделения. Согласование,
 организация и сопровождение аварийно-настроечных работ на оборудовании, линиях
 связи и IT-системах. Разработка проекта WEB приложения представления агрегированной
 информации метрик полученных от СМ Zabbix по утилизации и вышедшей емкости
 из-аварий каналов сети передачи данных на основе: языка программирования Python;
 Zabbix API; фреймворка Flask.

 Настройка и развитие мониторинга состояния сетевого оборудования и каналов связи в СМ
 Zabbix и визуализация полученных данных в Grafana. Создание скриптов на Python с

 Внедрение скриптов по сбору данных непосредственно с оборудования на Python с
 использованием модуля Netmiko. Проектирование системы визуализации топологии сети на
